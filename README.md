# Mila und Thea - Schule, Lernen und Aufgaben

Dieser Ordner ist ein eigenes Git-Repository fuer alles rund um Schule,
Lernen, Uebungen und Aufgaben von Mila und Thea.

## Struktur

- `Schule/` - Schulunterlagen, Fachnotizen, Termine
- `Lernen/` - Lernmaterial, Wiederholungen, Karteikarten, Uebungen
- `Aufgaben/` - Hausaufgaben, offene Aufgaben, erledigte Aufgaben

## Vorschlag fuer die Nutzung

- Neue Dinge zuerst in `Aufgaben/INBOX.md` sammeln.
- Groessere Themen nach Fach oder Datum in eigene Dateien verschieben.
- Regelmaessig mit Git speichern, wenn etwas Wichtiges dazukommt.
